# Ajou Menu · 亚洲大学食堂菜单

**[打开网站 →](https://zhupoxixixi-lang.github.io/ajou-menu/)**

电脑和手机可直接使用，无需登录、下载源码或填写 API 密钥。

## 功能

界面按 iPhone 原生风格设计：系统字体（SF / 苹方 / Apple SD Gothic Neo）、iOS 系统配色、自动深色模式，动画只用位移和透明度，开启“减弱动态效果”时自动关闭。

- **打开即是当前餐次**：按韩国时间和当天公告，自动显示当前或下一餐；右上角 **现在** 可随时回到自动选餐。
- **一屏看完整餐**：同一餐的所有窗口（A/B 窗口、外带、沙拉等）按卡片排列，每张卡片的第一道菜加粗显示为主菜。
- **周历选日期**：顶部周历直接点日期，左滑查看下周预告；没有菜单的日期显示为灰色。
- **分段切换**：食堂和餐次用 iOS 分段控件切换；在菜单区域左右滑动可切到上一餐或下一餐，跨到前一天或后一天。
- **记住选择**：语言和上次查看的食堂会保存在本机。
- **状态清楚**：供餐中、未开始、已结束、预告分别标色；休业、尚未公布、抓取失败和旧数据分别提示。
- **复制菜单**：复制整餐所有窗口的菜名，不含网页链接。
- **设置面板**：从底部弹出，可刷新菜单、查看学校原文和教职工食堂营业说明。
- **手机与离线**：支持添加到主屏幕；联网打开后可离线查看已缓存菜单。

## 数据与更新

菜单来自 [亚洲大学官方食堂公告](https://www.ajou.ac.kr/kr/life/food.do)，每日韩国时间 **00:00（KST）** 自动抓取和翻译；实际执行可能延迟。GitHub 运行器先经 Jina Reader 获取并校验学校原始页面，失败时回退直连；Reader 只接收公开网页地址，不接收翻译密钥。翻译使用 DeepSeek `deepseek-flash`（推理档位 `high`）并经过独立复核，翻译不完整时保留上一版已发布数据。

每次更新的翻译请求设有上限，未完成的内容会在后续更新中重试。

这是非官方菜单助手，实际供餐、临时调整和休业安排以学校公告为准。

网页不加载广告或分析脚本，翻译 API 密钥也不会进入公开页面。GitHub Pages 作为托管平台可能记录访问日志。语言、上次选择的食堂和离线菜单会保存在当前浏览器，可通过浏览器站点数据清除。

## 开发

项目是部署到 GitHub Pages 的静态 PWA，网站直接发布仓库根目录。改动可离线缓存的文件（`index.html`、`styles.css`、`menu.js` 等）时同时更新 `sw.js` 的缓存版本。

```sh
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
```

本地预览：在仓库根目录运行 `python -m http.server 8767 --bind 127.0.0.1`，打开 `http://127.0.0.1:8767/?lang=cn`。

本地抓取：在 `.env` 写入 `TRANSLATE_API_KEY`（参考 `.env.example`）后运行 `python -m scraper.main`，结果写入 `menu-data.js`。

界面采用原生 HTML/CSS/JavaScript，不依赖第三方 CDN。参考来源和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
